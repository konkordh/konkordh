# Konkordh

Chat e calls com os amigos.

- **Usar no navegador:** https://app.konkordh.com
- **Baixar para Windows:** [Konkordh-Setup.exe](https://github.com/konkordh/konkordh/releases/latest/download/Konkordh-Setup.exe)

Na primeira instalação o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. O app se atualiza sozinho depois de instalado.

Este repositório guarda só os instaladores.
